Help

Not answered here? Ask in the Discord.

How do I install Tidal?

Download the installer from the Download page, run it, then open Tidal from your desktop.

Which Minecraft versions work?

Minecraft 1.21 to 1.21.11 on the Fabric profile.

Do I need a paid account?

Online servers need a Microsoft account that owns Minecraft. Offline accounts work for singleplayer.

How do I open the menu?

Press Right Shift in game. You can change the key from the menu.

Which mods conflict with Tidal?

Tidal removes a conflicting mod (for example VulkanMod next to Sodium) and tells you which one. Remove the other mod and re-enable the one you want.

Windows says the app is unrecognized

Small apps often trigger this. Choose More info, then Run anyway, but only if you got the installer from this site.

The game won’t start

Use the Fabric profile, pick a version from 1.21 to 1.21.11, and restart the launcher. If it still fails, send your game log in the Discord.

Where do I report a bug?

In the Discord server. Include your game log if you have one.
